# VAIXLNS upload inbox

Upload **non-confidential files only** through a reviewed commit or pull request. This directory is inside a public GitHub repository. Never submit API keys, credentials, restricted datasets, medical records or private archives here.

After the GitHub workflow is merged and enabled, changes to this directory are automatically inventoried and routed to a **review proposal**. The source is not silently renamed, merged or published into another repository. Decisions remain `REVIEW_REQUIRED`, `BLOCKED` or `HELD` until separately reviewed.
