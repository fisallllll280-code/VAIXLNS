# VAIXLNS Ω Reality Forge — UI Prototype

This is a self-contained, interactive, browser-only concept for the Reality Forge command surface.

## Open locally

Open `index.html` in a modern browser. No package install, build step, credentials, or network connection is required.

## Current scope

- Interactive system constellation with selectable nodes.
- Agent-role filtering.
- Evidence admission requirements and decision protocol panels.
- Local-only design review / hold state.
- Motion pause and view reset controls.
- Explicit prototype-mode labeling to prevent sample data from being mistaken for live telemetry.

## Safety and truthfulness boundary

- All displayed counts, agent roles, event entries, and states are illustrative or registry-inspired samples.
- No live services, agents, telemetry, GitHub actions, or production APIs are invoked.
- A local design-review approval is not an engineering admission or release approval.
- `project.genome` and `registry/omega/omega-000-master-index.json` are not modified by this prototype.
- Before operational use, add read-only adapters bound to pinned repositories/commits, validate schemas and provenance, and retain fail-closed admission behavior.
