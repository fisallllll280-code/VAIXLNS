# VAIXLNS Agent Fabric

The agent package is an executable projection of the governed multi-agent boundary.

Core implementation:
- agent_fabric.py
- agent_wallet.py

The registry provides 13 specialized agents. Selection is capability-driven and authority-scoped.
Agent handoffs are typed and HMAC-authenticated.
Pattern use requires a private-language binding fingerprint and exactly four directions.
Wallet integration is paper-only and uses reservation, settlement, refund, and double-entry ledger evidence.

No raw private language source, personal identifier, or production signing key belongs in this package.
