# Research-to-Engineering Decisions

Every accepted research outcome that proposes implementation should create a traceable task with:
- parent research record ID and source revision;
- explicit acceptance criteria;
- affected repositories and paths;
- risk and authority classification;
- tests and expected evidence artifacts;
- rollback/recovery plan;
- owner and review boundary.

Do not auto-merge or publish from research output. Canonical index changes require separate authorized review. Research findings can inform tasks; they do not grant execution authority.
