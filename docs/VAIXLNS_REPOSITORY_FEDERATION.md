## Innovation boundary
Ideas are preserved separately from implementations. A code artifact may implement an innovation, but implementation does not by itself make the innovation canonical.

## No-loss rule
No historical artifact is silently deleted or overwritten during organization. Duplicate concepts are linked through lineage and reconciliation.

## Authority rule
Automatic discovery, classification, relationship detection, indexing, and projection are allowed. Canonical authority changes require the constitutional governance gate.
