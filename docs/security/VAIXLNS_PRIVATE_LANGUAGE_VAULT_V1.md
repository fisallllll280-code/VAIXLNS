# VAIXLNS Private Language Vault\n\n**Status:** IMPLEMENTED / CONFORMANCE PENDING  \n**Owner:** VAIXLNS  \n**Authority:** project.genome::v1.0.0 / Ω0_GENESIS_CORE\n\n## Boundary\n\nPrivate VAIXLNS language definitions and private pattern know-how remain outside the public repository. The repository contains only a sanitized vault contract and opaque references.\n\n## Subject binding\n\nThe lock is bound at runtime to two user-supplied secret values (identity and phone) through an HMAC-SHA256 binding key held outside Git. The raw values are never written to the repository, manifest, evidence, or logs by this component.\n\nAn independent unlock code is verified through a proof key held outside Git. The code is never stored in plaintext.\n\n## Authority\n\nUnlocking is an external-authority operation. The language guardian, pattern factory, code corrector, or other agent cannot self-unlock, self-promote, or rewrite the vault contract.\n\n## Storage\n\nProduction deployment should use Vault/HSM/KMS. The repository does not contain production secret material.\n\n## State\n\nLOCKED is the normal protected state. REVOKED disables the binding and requires an authorized reprovisioning path.\n\n## Important limitation\n\nCryptographic binding proves possession of the configured secret material; it does not by itself establish legal identity. Identity verification remains an external responsibility of the authoritative identity provider.\n
