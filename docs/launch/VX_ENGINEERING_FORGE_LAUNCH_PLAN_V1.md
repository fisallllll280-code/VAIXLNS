# VX Engineering Forge — Index-based launch package

Date: 2026-10-21. Status: PRE_RELEASE / NOT PUBLISHED. This is a derived engineering plan, not a canonical update.

## Product decision
Launch **VX Engineering Forge** first: a source-grounded engineering workspace that transforms a user intent into a bounded, independently tested, reproducible software artifact. Build separate product views for **ARC-X Assurance** and later **V-EXCHANGE**, but reuse VAIXLNS identity, Ω.000, NEXENT research, VX execution, VV verification and VCRE synthesis. Do not create redundant top-level systems.

## Work pipeline
Index read → provenance and lineage check → NEXENT/REDF candidate investigation → opportunity hypothesis (NEVER a guessed success percentage) → capability/authority check → isolated branch work → VV tests/replay → ARC-X independent evidence → verified release candidate → separate founder authorization FOR EACH RELEASE → verified publication adapter → postrelease telemetry.

## Model/provider adapter
OpenAI, Anthropic/Claude, Gemini, xAI, Mistral require distinct permissioned API connections: model IDs, cost/quota gate, endpoint/region, input/output schema, secret handle (never raw secrets in git), fail-closed auth, latency, capability and test receipt. This ChatGPT conversation is NOT a directly callable API integration; connecting OpenAI requires a separately configured API project. A catalog is not a proven live connection. With the zero-SAR ceiling, every paid or unknown-price invocation remains blocked.

## Market rollout (all HOLD)
1. Owned web staging → public web release after a signed revision-specific approval.
2. V-EXCHANGE listing (IP, marketplace contracts, verified seller, no invented payments).
3. GitHub Marketplace only for an eligible app/integration and successful review.
4. Google Play once Android binary/account/privacy requirements exist.
5. Apple App Store after functional iOS app, signing, testing, and review requirements.

Each channel needs version+artifact SHA, isolated staging, E2E and negative tests, independent verifier, policy checks, rollback, privacy terms, verified account ownership and explicit release approval. No publishing, merging to main, paid advertising, fees, or financial operations under this plan.
