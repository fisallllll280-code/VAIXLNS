## بوابات القبول والإغلاق

- **G0:** جرد وهوية وصلاحيات ونسخ مثبتة؛ بيئة معزولة ولقطة استعادة؛ حصر المراجع المحمية وربط كل اختبار بأمر وتوكيدات قابلة للتنفيذ.
- **G1:** T01–T05 جميعها PASS مع حالات سليمة وسلبية، وصفر فروق في المرجع المحمي.
- **G2:** T06–T10 جميعها PASS؛ إعادة إنتاج 3/3؛ استعادة من عملية جديدة ومخزن دائم دون فقد الأثر الملتزم أو تكراره.
- **G3:** T15 يثبت عمل بوابة الإصدار والتراجع في بيئة معزولة. يبقى `release_decision=HOLD` إلى حين اكتمال T11–T14؛ بيانات synthetic ليست إثبات تشغيل فعلي.
- **G4:** T11–T14 جميعها PASS على الأطراف والحواف المعلنة فعليًا؛ الهوية أو الطرف أو الصلاحية غير المتاحة تعطي BLOCKED.
- **G5:** مراجعة مستقلة لأدلة 15/15، الالتزام الجاري، البصمات وسلامة الملفات المحمية والتراجع. الحد النهائي `READY_FOR_REVIEW`؛ النشر والدمج لهما قرار منفصل.

## عقد تحديث حالة الاختبار

التسجيل في الفهرس لا يرقّي الاختبار أو النظام إلى VERIFIED. عند التشغيل تُحفظ لكل محاولة: `run_id` و`source_commit` والأمر والبيئة والسياسة والمدخلات ووقتا البدء والانتهاء و`exit_code` و`expected` و`actual` وروابط القطع وبصمات SHA-256 وهوية المراجع وقراره. تُحفظ المحاولات الفاشلة ولا تستبدل بنتيجة ناجحة منتقاة.

القيم `PASS/FAIL/BLOCKED/NOT_RUN` تخص نتيجة الاختبار. تبقى حالات السجلات `RECOVERED/CANONICAL/PROPOSED/IMPLEMENTED/VERIFIED` مستقلة، ولا تنشئ هذه الإحالة قرار اعتماد قنوني.
