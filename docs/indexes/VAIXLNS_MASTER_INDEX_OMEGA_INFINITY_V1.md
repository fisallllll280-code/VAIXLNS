## البصمات والتاريخ والسيادة

تُخزن كل نتيجة في مجلد اسمه SHA-256 لبيانها `manifest.json`. يتضمن البيان
بصمات اللقطة والسجلات ومخرجات Zero-Loss إن وجدت. إعادة البناء المتطابقة
لا تغيّر النتيجة. اختلاف المصادر ينتج مجلدًا جديدًا، ولا تُحذف اللقطات السابقة.
يوجد التحقق من سلامة الحزم دون الاتصال بالشبكة. البصمات ليست توقيع اعتماد.

معرّف كائن Git يستخدم `git-sha1`، ولا يُقدَّم على أنه SHA-256 لبايتات الملف.
بيانات الملفات البعيدة تحتوي `content_sha256: null` إلى أن تُجلب البايتات
ويُتحقق منها. سجل Zero-Loss المحلي يحفظ SHA-256 للمحتوى المقروء فعلًا، لكن
نطاق النسخة المحلية منفصل عن مراجعة الشجرة البعيدة المسجلة في اللقطة.

لا يدمج السجل `VLNS/NAXLNS` أو `NEXNET/NEXENT`، ولا يمنح اعتمادًا تشغيليًا
للابتكارات أو الفروع أو الخدمات. VAIXLNS يبقى جهة السيادة؛ `project.genome`
و`Ω.000` دون تعديل. لا تتحول الحالات المعلنة إلى إثباتات. لا تُنشأ عناصر
تاريخية مفقودة لاستكمال النطاق 0001–2750 بصورة مصطنعة.

## التشغيل والتحقق

```bash
# الجرد البعيد المحفوظ فقط
python scripts/build_master_index.py \
  --capture registry/indexes/master-index-capture.2026-10-25.v1.json \
  --output-dir build/master-index

# الجرد نفسه مع الفهارس الدلالية الـ28 للنسخة المحلية الحالية
python scripts/build_master_index.py \
  --capture registry/indexes/master-index-capture.2026-10-25.v1.json \
  --root . --output-dir build/master-index-with-semantics

# استبدل SNAPSHOT_SHA256 باسم مجلد النتيجة
python scripts/build_master_index.py --verify build/master-index/SNAPSHOT_SHA256

python -m unittest discover -s tests -p test_master_index.py -v
python -m unittest discover -s tests -p test_zero_loss_index.py -v
```

تختبر المجموعة الجديدة ثبات البناء، وحفظ اللقطات السابقة، وكشف التلاعب،
ورفض الأشجار المبتورة والمعرّفات العائمة والتكرارات والمسارات غير الآمنة،
والفصل بين الهويات، وإعادة استخدام Zero-Loss دون ترقية تلقائية.

ينفذ Workflow البناء والتحقق ويرفع حزمة الأدلة. احتفاظ GitHub Actions
بالمخرجات محدود زمنيًا، وليس بديلًا عن النسخ الاحتياطية الدائمة. اللقطة
المصدرية محفوظة في Git؛ ينبغي إضافة لقطات جديدة باسم جديد بدل استبدالها.
الفهرس ليس نسخة احتياطية لمحتوى جميع الفروع أو بديلًا عن آلية
`capture_pinned_repo_snapshots.py` الحالية وحزم الاستعادة الخاصة بها.
