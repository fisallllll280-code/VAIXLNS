# VAIXLNS one-pass application preparation
Version 1: local-only registration assistant. Open web/gov-sand-quick-registration/index.html.

Choose Eatizaz / MOD supplier / Jadeer; enter project title, role and a non-confidential summary once; view agency-specific checklist; copy or download draft; follow the official URL and submit there only if authorized. The page never claims to submit or validate external identity and does not persist values.

Further improvements after approval: server-side verified company profile vault with opt-in reuse, form schemas from official sources, signed submission receipts, human-in-loop steps, expiry checks, multilingual accessibility audits, allowed official APIs. None are implemented by this local prototype.
