# VAIXLNS Ω∞ — لوحة ترتيب الأفكار والتنفيذ
**مرجع:** registry/gov-sand/priority-roadmap.v1.json | **تاريخ:** 2026-10-27

## قاعدة الأولوية
المديونية الشخصية عاجلة ولكن لا تُخلط بأموال المشروع. بعد ذلك إثبات نموذج سَنَد ثم مسار شراكة اعتزاز والملكية الفكرية، ثم الفهرس الحي، الواجهات، التكاملات والتمويل. لا يعني ترتيب الفكرة اعتمادها حكوميًا أو حصول التمويل.

## خريطة الفهارس
P01 = ملف شخصي منفصل، P02/P10 = MIL، P03/P04/P09 = GOV، P05 = CORE، P06 = UX، P07 = ARCH، P08 = FIN.

## تسلسل العمل
1. أغلق نواقص مستندات المديونية الحقيقية عبر قنوات ناجز والبنك (لا ترفعها إلى GitHub).
2. أثبت نسخة سَنَد تجريبية بإحصاءات واختبارات قابلة للإعادة.
3. اعرض اعتزاز خطابًا غير سري بعد التحقق من الصفة القانونية.
4. ثبّت سجل حقوق وملكية وتأريخ التطورات السابقة دون حذف أو دمج صامت.
5. انقل نتائج الاختبارات من CI إلى فهرس عالمي للإنجاز، بوصفها أدلة محددة النطاق.
6. ركّب عقود تكامل للإصدارات والهوية والموافقات ولا تشغّل أي محول حكومي أو مصرفي دون تفويض.

## تعريف الإنجاز
PROPOSED = فكرة، DOCUMENTED = وثيقة، DESIGNED = تصميم، TESTED_LIMITED = اختبار محدود، BLOCKED = يحتاج تصريح/اعتماد، ACTION_REQUIRED = إجراء واقعي مطلوب. لا تُستخدم كلمة DEPLOYED لأي ربط بلا سجل نشر وقياس حي.

## المراجعة الأسبوعية
حدث كل بند مع مصدر، مسؤول، خطر، خطوة تالية، ودليل. احفظ السجلات التاريخية بمراجعها. لا تُرقّي الحالة اعتمادًا على تقرير مولّد من الذكاء الاصطناعي وحده.
