Project, System, Subsystem, Innovation, Idea, Language, Model, Protocol, Algorithm, Engine, Mind, Intelligence, Agent, Artifact, Evidence, Capability, Authority, Pattern, Version, Lineage, Repository.

The registry resolves canonical ownership without destroying historical lineage.
