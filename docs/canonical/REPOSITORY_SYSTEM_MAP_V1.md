## Ordering rule

Repository order is computed from role, authority, dependency, evidence and lifecycle.

Priority dimensions:
1. Canonical authority
2. Constitutional dependency
3. Runtime dependency
4. Evidence maturity
5. Lineage continuity
6. Operational responsibility
7. Research distance from production

Names never override evidence.

## Separation rule

One concept may have many references and implementations, but one canonical owner after canonicalization.

SOURCE -> EVIDENCE -> IDENTITY -> RELATION -> STATUS -> CANONICAL OWNER

## State rule

Use these states consistently:

VERIFIED
IMPLEMENTED
SPECIFIED
PARTIAL
MISSING
CONFLICT
PROPOSAL
RECOVERED
QUARANTINED

No document-only assertion upgrades an object to VERIFIED.

## Boundary rule

NEXENT may discover, model, synthesize, simulate and propose. VAIXLNS controls canonical adoption and production authority. No silent cross-boundary mutation is allowed.
