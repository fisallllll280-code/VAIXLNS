# VXSL — Canonical System Language Boundary V1

VXSL is the declarative semantic language for describing a VAIXLNS system before implementation.

Source semantics:
domains + quantities + laws + states + constraints + capabilities + minds + simulations + proofs + interfaces + ownership + lineage

Implementation languages are targets. The canonical meaning is not owned by any individual runtime language.

## Four-domain core
MATHEMATICS + PHYSICS + ENGINEERING + COMPUTING

## Reference target roles

Julia/Python: scientific and numerical computation
Rust/C++/CUDA: runtime and accelerated kernels
WebAssembly: portable sandboxed artifacts
TypeScript: mission interface
OpenUSD: digital-twin representation
SQL/Arrow: data
