# Cabsolute Prompt AI — VAIXLNS Governed Submission Orchestrator (proposal)

Status: PROPOSED; no active service, model binding, or execution automation is claimed.

## Mission
Coordinate dossier authoring, repository provenance, assurance tests, compliance mapping, business case and presentation through specialized VX-bound agents while maintaining sovereign approval gates.

## Agent responsibilities
- IntakeAgent: classify stakeholder and submission requirements; never invent eligibility.
- RepositoryAgent: inventory read-only source and pin SHA, preserve historical identities.
- IndexAgent: reconcile original/derived innovations and recovery gaps.
- EngineeringAgent: find implementation anchors, interfaces and tests; no unsafe edits.
- TestAgent: construct T01–T15 test map; execute only after G0 and authorization.
- EvidenceAgent: collect raw test logs, SHA-256, provenance and independent reviewer identity.
- ComplianceAgent: map applicability to current cited obligations, flag legal review.
- FinanceAgent: build labeled scenarios; no live transactions without authorization.
- PresentationAgent: prepare disclosure-safe executive material.
- AssuranceAgent: independently challenge claims and refuse unsupported VERIFIED.
All agents are logical roles only; installation and runtime binding remain unverified.

## Invocation protocol
INPUT: request_id, objective, target_audience, pinned_source_refs, scope, explicit_permissions, budget_sar=0, protected_paths.
STEPS:
1. DISCOVER canonical existing artifacts and duplicates before creating new.
2. COMPARE requirements against observed code, configuration, evidence and risks.
3. SIMULATE proposed execution in a restricted environment, clearly labeled SIMULATED.
4. GATE policy, scope, secrets, and G0 tests.
5. EXECUTE authorized tests in a safe branch with no deployment.
6. PROVE each claim using primary logs and a reviewer distinct from generating agent.
7. PACKAGE redacted public and controlled confidential versions.
OUTPUT: status PROPOSED|IMPLEMENTED|VERIFIED|BLOCKED; claims, evidence refs, uncertainties, next safe actions.

## Decision boundaries
Agents propose; the VAIXLNS governance gate authorizes; VX executes only explicitly authorized work; evidence receipts record outcomes, not authority; human owner approves merges, spending and release.
Never elevate repeated summaries or outputs sharing a single origin as independent confirmations.
Fail closed on missing source authority, ambiguous identity, endpoint access or evidence.
