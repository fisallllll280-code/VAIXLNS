# VAIXLNS — Execution Waves v1

W0 INVENTORY
- enumerate systems, operations, files, repositories and entrypoints.

W1 STATIC
- schemas, syntax, imports, configuration, dependency and policy checks.

W2 UNIT SIMULATION
- isolated component scenarios and expected-state comparison.

W3 COMPONENT
- executable component tests.

W4 SUBSYSTEM
- contract and integration tests.

W5 SYSTEM
- integrated runtime execution.

W6 CROSS-SYSTEM
- federation and interface simulations.

W7 REPLAY
- reproduce failed and critical runs from evidence snapshots.

W8 RECOVERY
- exercise rollback, restoration and degraded-mode procedures.

W9 PROOF
- promote only evidence-backed states.

A failed wave blocks promotion of the affected target but does not delete its source or historical record.
